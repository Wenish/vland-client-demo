# Default behavior for casting skills

Currently:\
Currently when pressing the skill key it quick cast the spell and SHIFT + Key it shows the spell.\
\
Should:\
It should be the other way around.\
Per default when pressing key for a spell it should show spell preview indicator.\
And with SHIFT + key should quick cast the spell.
