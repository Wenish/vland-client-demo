# Unit Highlight when using Spell preview indicator

Currently:\
When hovering a unit with the mouse the unit will get a highlight.\
\
Should:\
It should still highlight the unit which gets hovered.\
\
Expection when it in spell preview modus and it is previewing a spell that snaps to units (smart targeting) then it should highlight the unit it snaps to for the targeting preview and not the unit which gets hovered.
